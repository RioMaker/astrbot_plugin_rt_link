网页成绩 token

网页成绩 token 用户指南与开发者 API 文档

Sakura Taiko Viewer / scoretoken

网页成绩 token

它是一把只读密钥，让你授权的网页、工具或服务读取当前绑定太鼓 ID 的最新完整 userdata。

返回多端同步

用户使用指南

  1. 1

    登录 Viewer，进入“个人账户 > 多端同步”。

  2. 2

    确认页面顶部显示的是你要授权的当前绑定 ID。

  3. 3

    点击“生成 token”，立即保存本次唯一展示的 48 位 token，并填写到需要接入的应用中。

  4. 4

    怀疑泄露时，在同一页面轮换或撤销 token；旧 token 会立即失效。

安全须知

token 等同于成绩读取密码。不要发到群聊、截图、前端源码或公开仓库。Viewer 和 bot 管理的是同一个 token，在任意一端重新生成都会让旧 token 失效。

开发者 API

MethodPOST
Endpointhttps://sakura-bot.cn/api/public-score/by-token
Content-Typeapplication/json

请求

curl -X POST "https://sakura-bot.cn/api/public-score/by-token" \
  -H "Content-Type: application/json" \
  -d '{"token":"用户的48位token"}'

常见错误

400请求体或 token 字段不合法
401token 无效、已轮换或已撤销
404绑定 ID 或本地成绩不存在
502上游成绩拉取失败

接入约束

  • 接口支持 CORS，可由浏览器直接请求；有后端时建议服务端代调用，减少 token 暴露。
  • 接口返回前会尝试拉取最新成绩。请避免高频轮询，并在业务侧设置短时间缓存。
  • 不要把 token 写入日志、埋点、URL 查询参数或错误上报。
