# R2：固定定数封顶的非线性玩家 Rating

版本：v0.18.0 / `taiko-signal-rhythm-v2-r2-constant-cap-envelope-v1`。

## 规则与公式

固定定数 C 不随玩家变化。精度 A 延续 `(良 + 可 × 0.5) / 总音符数` 与历史全良标志规则，只对可靠匹配、达到既有 75% 精度门槛的记录评级。R2 保证 `0 ≤ Rating ≤ C`，且只有全良精度 100% 才达到 C。低于 100% 的结果在数值上严格小于 C，图片也不会把两位小数四舍五入后的未全良表现画成已达到上限。

令旧评分曲线为 `F(C,A)`，先计算：

```
R0(C,A) = C × F(C,A) / F(C,1)
R(C,A)  = max { R0(D,A) : D 为不大于 C 的合法定数 }
```

第一步把每个难度已有的非线性曲线归一到自身定数，不再出现 Rating 大于定数；第二步取难度方向的单调包络，修正旧曲线归一化后少数“同精度，高定数反而低分”的区间。没有手写新的经验曲率系数，也没有用单个玩家样本训练曲线。同定数共用曲线，不同定数的曲率仍不同。75% 是既有评级参与门槛，不额外规定它必定映射为零。

对于每个 D，有 `R0(D,A) ≤ D ≤ C`，因此包络仍不超过 C。全良时各候选等于各自定数，最大值恰为 C；非全良时仍严格低于 C。实现对非全良端额外使用浮点相邻值保护，防止数值舍入碰到上限。

这种曲率是继承旧模型的初始设计，并非已经用多玩家真实水平校准的新能力标准。后续若调整曲率取向，应基于独立数据并再次提升算法版本。

## 关联计算

- AI 单谱 Rating 与由它计算的七维、节奏/配置处理评分同步更新。
- 配置理论满分由内置已核验 BPM7 配置画像全良重算：1,413 张画像、116 个配置。只更新分母、算法版本和资源哈希，不改解析画像、TJA 指纹、物量及固定定数。脚本：`scripts/recompute_configuration_ceilings.py`。
- 综合 Rating 沿用既有去重、Top20 聚合规则，不另行修改为均分或新的加权规则。主 Rating 量表上限为当前合法定数最大值 11.6；界面环、阶段刻度及颜色按新量表同步调整，七维量表保留其独立含义。
- OurTaiko-v1 参考计算继续使用旧 `calc_reference_rating`，不把 AI 新曲线套入参考模型。

## 缓存与历史迁移

缓存 schema 升至 8，重新同步计算。Rating 历史使用新算法标识；配置历史同时按新算法版本和资源哈希隔离。旧历史和原始成绩不删除。

玩家 Rating 基线记录算法版本。旧模型到 R2 的首次同步只建立新 Rating 基线，不把公式重算差异标成玩家提升或下降；最高分仍按同账号、服务器和来源的最近一次已保存成绩比较。完成基线后，再次同步才标注同模型玩家 Rating 的真实变化。

## 验证方式

全部 63 个合法定数，各检查 1,001 个 75%–100% 精度点，共 63,063 点：有限性、精度单调、难度单调、严格封顶和全良端点；额外验证非线性及不同难度的相对曲线差异。离散检查不代替整体数学论证；上述包络不等式另行保证上限。

另覆盖旧参考公式、新旧基线隔离、旧配置资源拒绝、缓存失效、重启、分支匹配、显示舍入边界、配置全良分母复算及图片渲染。真实缓存回放仅作为本地历史数据验证，不代表线上 AstrBot、QQ 或当前 API 已验证。
